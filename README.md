Cap Runner
Бесконечный раннер в духе игры с динозавром из Chrome. Только вместо динозавра — парень в камуфляжной кепке, вместо кактусов — мусорные баки, а вместо серой пустыни — яркий город с закатным небом.
Играть: https://ВАШ-НИК.github.io/ВАШ-РЕПОЗИТОРИЙ/

Управление

| Действие | Клавиши | Телефон |
|----------|---------|---------|
| Прыжок | `Пробел`, `↑`, `W` | касание экрана |
| Старт / рестарт | `Пробел`, `Enter` | касание экрана |
| Пауза | `P` | — |
Возможности

- Персонаж в кепке, розовых очках и худи с анимацией бега и прыжка
- Мусорные баки разных цветов и размеров, иногда по два подряд
- Скорость растёт вместе со счётом
- Яркий фон: градиентное небо, солнце, облака, дальний город с параллаксом
- Рекорд сохраняется в браузере (`localStorage`)
- Работает на компьютере и телефоне
Технологии

HTML5 Canvas и чистый JavaScript. Без библиотек, сборки и установки. Вся игра находится в одном файле `index.html`.

 Запуск

```bash
git clone https://github.com/ВАШ-НИК/ВАШ-РЕПОЗИТОРИЙ.git
```

Откройте `index.html` в браузере.

Публикация на GitHub Pages

1. Загрузите `index.html` и `README.md` в репозиторий.
2. Settings → Pages, ветка `main`, папка `/ (root)`, Save.
3. Через минуту игра откроется по ссылке выше.

 Как настроить под себя

В начале скрипта в `index.html`:

- цвета баков: массив `CC`
- стартовая скорость: `sp=6` в функции `reset`, максимальная: `15` в функции `U`
- высота прыжка: число `-15.5` в функции `act`
